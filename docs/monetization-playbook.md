# Monetization Playbook - ogx

This is a commercial planning artifact, not a revenue guarantee. It exists to turn an archived technical proof into a clear, ethical selling motion.

## Commercial Lane

- **Lane:** CLI orchestration and team automation layer
- **Primary buyer:** Developer platform teams, AI tool builders, DevOps leads, and agencies running multi-agent workflows.
- **Why this can sell:** Teams need repeatable orchestration, visibility, and cancellation controls when AI CLI work moves beyond solo prompts.

## Offer Ladder

1. **Workflow automation setup** - $3k-$15k. Install task graph, team sessions, and review pack for a delivery team.
2. **Internal developer tool pilot** - $20k-$80k. Adapt orchestration, MCP, and HUD surfaces to a real engineering workflow.
3. **Sponsored integration or pro plugin** - $2k-$20k/month. Fund connectors, hosting, support, or branded distribution.

## Acquisition Channels

- Developer tool demos
- Open-source community distribution
- Integration content for AI CLI ecosystems

## Proof Gates Before Selling

- Tests and build pass
- Doctor route exposes dependency freshness
- Archived status points to active orchestration repos

## Risk Boundaries

- Do not market archived code as fully supported SaaS
- Keep secret-handling guidance conservative
- Avoid implying autonomous completion without human review

## 30/60/90 Day GTM

- **30 days:** Publish a five-minute team workflow demo
- **60 days:** Create a comparison page for CLI orchestration use cases
- **90 days:** Offer a paid setup for small delivery teams

## Metrics That Matter

- Setup conversions
- Active team sessions
- Task completion reliability
- Integration sponsors

## Positioning Note

Keep the repository's archived status visible. Sell the reusable workflow, diagnostic, enablement material, or pilot path that the proof makes credible; do not sell the archive as an unsupported production service.
