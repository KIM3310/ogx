ogx CLI multi-agent

Coordinate Gemini agents without losing the operator thread.

ogx is a CLI-first product for setup, doctoring, launch, and tmux-based teamwork. The browser surface stays intentionally honest: it points reviewers to the strongest walkthrough first — npm install, npm run smoke, then the real CLI commands — and only leans on hosted routes when a wrapper is actually useful.

Primary surfaces

  • ogx setup for project bootstrap
  • ogx doctor for environment and notification checks
  • ogx launch for isolated Gemini runtime execution
  • ogx team for tmux-based multi-agent coordination
  • Optional Cloud Run API wrapper for health, status pack, and doctor routes

First command path

  • Run npm install and npm run smoke for the shortest honest proof loop.
  • Run ogx setup and ogx doctor before launch so the operator path is grounded.
  • Use the hosted wrapper only when a reviewer explicitly needs a web surface.

When the hosted wrapper actually matters

01 · CLI-first proof

Start with setup and doctor so the operator story is grounded before anyone assumes a browser is required.

02 · Review surface only

Use the hosted wrapper when a reviewer needs health, review-pack, or doctor routes without walking the whole terminal flow live.

03 · Runtime handoff

Move back to launch and team only after the environment and trust-boundary story is already easy to repeat.
